s vedlejšími taby) JEDNÍM klidným horizontálním tab-řádkem nahoře panelu
(stejný vizuální jazyk jako Blackbook/Profit centrum — `.report-nav` /

katalog, bulk modal, chemky cena, undo bar…) zůstávají BEZE ZMĚNY — mění se
jen jak se mezi panely přepíná a jak vypadá karta okolo.

3) JS — najdi funkci `skladTab(id)` a nahraď ji touto verzí (jen mění
   selektor tříd, chování je identické):

function skladTab(id){
  document.querySelectorAll('.report-nav-item').forEach(el=>el.classList.toggle('active',el.dataset.panel===id));
  document.querySelectorAll('.sklad-panel').forEach(el=>el.classList.toggle('active',el.id==='panel-'+id));
  try{localStorage.setItem('albion_sklad_tab',id);}catch(e){}
  if(id==='nevyrizene' && window.loadNevyrizene) window.loadNevyrizene();
}

   A SMAŽ celou funkci `skladToggleMore()` a její volání v `restoreTab()`
   IIFE (ten `(function restoreTab(){...})()` blok) — nahraď ho jednodušší
   verzí bez "Více" logiky:

(function restoreTab(){
  try{
    const saved=localStorage.getItem('albion_sklad_tab');
    if(saved && document.getElementById('panel-'+saved)) skladTab(saved);
  }catch(e){}
})();
